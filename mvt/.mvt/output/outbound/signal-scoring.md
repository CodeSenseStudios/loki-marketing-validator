# Signal Scoring

| Signal | Score | Indicator |
| Strong intent | 5 | I would pay for this today |
| High interest | 4 | This sounds useful and relevant |
| Mild interest | 3 | Interesting, maybe later |
| Polite deflection | 2 | Send me more info |
| No fit | 1 | Problem does not resonate |

Go signal: average score >= 3.5 across 5+ interviews.
