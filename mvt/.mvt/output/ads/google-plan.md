# Google Ads Plan

## Campaign Structure
- Search: high-intent validation terms
- Display remarketing: return visitors and high-engagement users

## Ad Groups
- demand validation software
- waitlist testing
- product validation tools

## Keywords
- [demand validation software]
- "waitlist experiment"
- [product validation landing page]

## Negative Keywords
free, jobs, agency, course, template

## Bidding
Start with Manual CPC, move to target CPA after enough conversions.

## Budget Split
60% search / 40% display
