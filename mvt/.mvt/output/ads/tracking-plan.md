# Tracking Plan

## GTM Container
- Tags for GA4 page view, waitlist signup, referral share
- Variables for UTM source, medium, campaign, content, and term

## GA4 Events
- page_view
- waitlist_signup
- referral_share
- email_capture

## Platform Pixels
- Meta: PageView, Lead
- Google Ads: signup conversion
- LinkedIn: signup conversion

## UTM Schema
- utm_source: google|meta|linkedin|reddit|organic
- utm_medium: cpc|social|email|referral
- utm_campaign: {experiment-name}-{platform}-{audience}
- utm_content: {creative-variant-id}
- utm_term: {keyword}

## Attribution
Use last-click attribution for the experiment period.
